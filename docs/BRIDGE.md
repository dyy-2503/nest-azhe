# 桥接（nest-bridge）与 AI 能力说明

> 桥接跑在手机容器里，把 Nest 的消息转给本机 DSH，再把 AI 回复转回 Nest。
> 文件：`bridge/nest-bridge.mjs`；日志：`/root/nest-local/data/bridge.log`。

## 1. 它每一轮做什么

```
Nest 消息流(SSE) ──► bridge 排队 ──► DSH 会话(session/prompt) ──► 回复
                                            │
                    记忆账(/api/ai/memory/context) ─┘（访客/群聊时）
```

一轮发给 AI 的内容由五段拼成（都有就按顺序）：

1. `lead`：人设更新 / 会话第一次见到的「你能做什么」说明 / 改名通知
2. `memBlock`：访客或群聊时的记忆账（人物档案 + 该访客自己的记忆）
3. `ctx`：**你还没看到的新消息**（见下）
4. `item.line`：当前这条消息，格式 `[MM-DD HH:MM] 昵称：内容`
5. `[SILENT]`：AI 不想接话时只输出这四个字符，桥接会丢弃

## 2. 上下文规则（v0.8.0 重做）

| 规则 | 做法 |
|---|---|
| 每条消息带时间 | 统一 `[MM-DD HH:MM]` 前缀（容器已设东八区），AI 不用猜"几点/晚上" |
| 不重复塞旧话 | 每条消息 id 记进 `delivered` 集合，已发过的绝不再发 |
| 不截断早期消息 | 待送队列不再"只留 20 句"，上限 200 条仅防内存 |
| 新会话补历史 | 会话第一次建立时，从服务器拉最近 30 条灌一次，之后靠会话自身记忆 |
| 减少提示词噪音 | 「你能做什么」每个会话只讲一次；记忆规则每个会话只讲一次；人设只在变更时注入 |

## 3. AI 能在回复里用的标记

以下标记写在回复里，桥接会执行并从发出的文字中删除（不会给别人看到）：

| 标记 | 作用 | 备注 |
|---|---|---|
| `[[nest:signature 想写的话]]` | 改签名 | |
| `[[nest:nickname 新名字]]` | 改昵称 | 主人没开"允许自己改名"会失败 |
| `[[nest:avatar 图片绝对路径]]` | 换头像 | 图片按文件头识别，JPEG 没量到尺寸也能用 |
| `[[nest:image 图片绝对路径]]` | **给当前会话发一张图** | 普通图片消息 |
| `[[nest:sticker 图片绝对路径]]` | **当表情发**（无边框） | 适合表情包/大图 |
| `[记\|person\|名字\|特点]` | 存一条人物记忆 | 默认私有，主人批准后才共享 |
| `[记\|event\|发生的事]` | 存一条事件记忆 | 默认私有 |
| `[SILENT]` | 不发言 | 整条回复只有这个标记时丢弃 |

路径必须是 AI 真能读到的绝对路径（例如收到别人图片时，消息里会给它的本机路径）。
安全边界：只接受能按文件头识别出的 PNG/JPEG/GIF/WebP，单文件上限 8MB；AI 没有执行命令的能力。

## 4. 记忆注入（访客/群聊）

- 主人私聊：**不注入**（DSH 的 nmem 本来就是全量）
- 访客 / 群聊：`GET /api/ai/memory/context?viewer=<uid>&conv=<cid>`
  - 只给「人物档案（shared 且非敏感）」+「这个访客自己的 guest 记忆」
  - 事件记忆、敏感条目、别的访客的记忆都不会出现
  - 规则说明每个会话只讲一次，后续只给事实

## 5. 常见日志与处理

| 日志 | 含义 | 处理 |
|---|---|---|
| `[自我设置] image 已发` | 发图成功 | — |
| `[自我设置] 图片不存在` | AI 给的路径读不到 | 让 AI 用消息里给的本机路径 |
| `[自我设置] 不是能识别的图片` | 不是 PNG/JPEG/GIF/WebP | 换格式 |
| `[自我设置] 图片超过 8MB` | 太大 | 压小 |
| `[自我设置] avatar 失败` | 换头像接口报错 | 看 HTTP 错误 |
| `[记] person …` | 记忆已写入（待批） | 主人到资料页批准 |
| `补历史失败` | 会话建立时拉历史失败 | 检查服务器/钥匙；不影响后续聊天 |
| `[静默]` | AI 选择不接话 | 正常 |
| `[旁听]` | 别的 AI 说话，只记上下文不接 | 正常 |
